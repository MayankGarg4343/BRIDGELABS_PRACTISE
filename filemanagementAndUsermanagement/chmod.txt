LINUX COMMAND NOTES – chmod (Change File Permissions)

1. OVERVIEW

Command: chmod

Purpose: Changes file and directory permissions.

Why it is used: - Control who can read, write, or execute files. -
Secure sensitive files. - Allow applications and scripts to run.

Problem it solves: Prevents unauthorized access while granting
appropriate permissions.

  --------------------------------------------------
  2. PERMISSION BASICS
  --------------------------------------------------
  Permission Types r = Read (4) w = Write (2) x =
  Execute (1)

  Permission Classes u = User (owner) g = Group o =
  Others a = All (u+g+o)
  --------------------------------------------------

3. SYNTAX

chmod [options] MODE FILE

Examples: chmod 755 script.sh chmod u+x script.sh

  --------------------------------------------------
  4. NUMERIC (OCTAL) MODE
  --------------------------------------------------
  777 = rwxrwxrwx 755 = rwxr-xr-x 750 = rwxr-x— 700
  = rwx—— 666 = rw-rw-rw- 644 = rw-r–r– 640 = rw-r—–
  600 = rw——-

  Calculation: r=4, w=2, x=1 Example: 7 = 4+2+1 =
  rwx 5 = 4+1 = r-x 6 = 4+2 = rw-
  --------------------------------------------------

5. SYMBOLIC MODE

-   Add permission
-   Remove permission = Set exact permission

Examples: chmod u+x file chmod g-w file chmod o=r file chmod a+r file
chmod ug+rw file

  --------------------------------------------------
  6. IMPORTANT OPTIONS
  --------------------------------------------------
  -R Apply recursively.

  -v Verbose output.

  -c Report only changed files.

  -f Suppress most error messages.

  –reference=FILE Copy permissions from another
  file.
  --------------------------------------------------

7. EXAMPLES

chmod 644 notes.txt chmod 755 script.sh chmod -R 755 website/ chmod u+x
backup.sh chmod g-w report.txt chmod o-r secret.txt chmod
–reference=file1 file2

  --------------------------------------------------
  8. BEST PRACTICES
  --------------------------------------------------
  - Avoid 777 unless absolutely necessary. - Give
  minimum required permissions. - Use recursive
  changes carefully. - Verify permissions with ls
  -l.

  --------------------------------------------------

9. COMMON USE CASES

• Make shell scripts executable. • Secure SSH keys. • Remove public
access. • Prepare web server directories. • Match permissions between
files.

  ------------------------------
  10. SCENARIO-BASED QUESTIONS
  ------------------------------

1.  Make a script executable. Answer: chmod +x script.sh

2.  Set permissions to rwxr-xr-x. Answer: chmod 755 file

3.  Remove write permission from group. Answer: chmod g-w file

4.  Apply permissions recursively. Answer: chmod -R 755 directory

5.  Copy permissions from another file. Answer: chmod –reference=source
    target

6.  Which option displays changes? Answer: -v or -c

7.  Why avoid chmod 777? Answer: It grants full access to everyone and
    is a security risk.

8.  What problem does chmod solve? Answer: It controls file and
    directory access.

9.  What does chmod 600 mean? Answer: Owner has read/write; group and
    others have no permissions.

10. Which command verifies permissions? Answer: ls -l
