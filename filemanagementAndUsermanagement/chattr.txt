LINUX COMMAND NOTES – chattr (Change File Attributes)

1. OVERVIEW

Command: chattr

Purpose: Changes special filesystem attributes on Linux files and
directories (primarily ext2/ext3/ext4).

Why it is used: - Protect important files from modification. - Prevent
accidental deletion. - Make log files append-only. - Improve security
for critical configuration files.

Problem it solves: Normal permissions (chmod) are sometimes
insufficient. chattr adds filesystem- level protections that can prevent
changes even by privileged users.

  --------------------------------------------------
  2. SYNTAX
  --------------------------------------------------
  chattr [options] [+|-|=ATTRIBUTES] FILE…

  + Add attribute - Remove attribute = Set exact
  attributes
  --------------------------------------------------

3. COMMON ATTRIBUTES

+i Immutable. Cannot modify, rename, delete, or create hard links.

-i Remove immutable flag.

+a Append-only. Existing data cannot be modified; only appended.

-a Remove append-only flag.

+A Do not update access time (atime).

+d Exclude from dump backups.

+j Data journaling (filesystem support dependent).

+s Secure deletion (support depends on filesystem).

+u Undelete information (support depends on filesystem).

  --------------------------------------------------
  4. IMPORTANT OPTIONS
  --------------------------------------------------
  -R Apply recursively.

  -V Verbose output.

  -f Suppress most error messages.
  --------------------------------------------------

5. EXAMPLES

Protect a file: chattr +i /etc/passwd

Remove protection: chattr -i /etc/passwd

Append-only log: chattr +a /var/log/app.log

Recursive immutable: chattr -R +i /important

Verify attributes: lsattr filename

  --------------------------------------------------
  6. BEST PRACTICES
  --------------------------------------------------
  - Use +i only for critical files. - Remove +i
  before updates. - Use +a for log files. - Verify
  changes with lsattr. - Root (or appropriate
  capability) is generally required.

  --------------------------------------------------

7. COMMON USE CASES

• Protect configuration files. • Prevent ransomware or accidental
deletion. • Secure audit logs. • Lock application configuration after
deployment. • Troubleshoot immutable files.

  -----------------------------
  8. SCENARIO-BASED QUESTIONS
  -----------------------------

1.  Prevent a file from being modified. Answer: chattr +i file

2.  Remove immutable protection. Answer: chattr -i file

3.  Make a log append-only. Answer: chattr +a logfile

4.  Apply immutable recursively. Answer: chattr -R +i directory

5.  Which command verifies attributes? Answer: lsattr

6.  A file cannot be deleted even by root. What should you check?
    Answer: Run lsattr to see if the immutable (i) attribute is set.

7.  What problem does chattr solve? Answer: It provides filesystem-level
    protection beyond standard permissions.

8.  Which attribute is commonly used for log files? Answer: +a
    (append-only)

9.  Why remove +i before editing? Answer: Immutable files cannot be
    modified until the attribute is removed.

10. What is the difference between chmod and chattr? Answer: chmod
    changes permissions; chattr changes filesystem attributes that can
    further restrict file operations.
