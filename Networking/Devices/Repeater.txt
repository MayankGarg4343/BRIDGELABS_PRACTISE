TOPIC: REPEATER — Full Notes

1. DEFINITION

Repeater ek Layer 1 (Physical Layer) networking device hai.

Main purpose:
- Weak/degraded physical signal receive karna
- Signal ko recover/regenerate karna
- Regenerated signal ko aage transmit karna

Simple definition:

Repeater network signal ko physically regenerate karke network
communication distance/segment ko extend karne mein help karta hai.


2. OSI LAYER

Repeater:
Layer 1 = Physical Layer

Repeater primarily physical signals/bits ke level par operate karta hai.


3. MOST IMPORTANT CONCEPT

Repeater packet ko intelligently forward nahi karta.

Better statement:

Repeater physical-layer signal ko receive, recover/regenerate aur
retransmit karta hai.

5. REAL-LIFE ANALOGY

Long corridor:

Person A -------- Person B

Voice weak ho sakti hai.

C signal/message ko clearly aage relay karta hai.

6. WHY REPEATER IS NEEDED

Physical signals distance ke saath degrade ho sakte hain.

Main problem:
- Attenuation
- Noise
- Signal degradation
- Distance limitations

Repeater signal ko regenerate karke next segment par transmit karta hai.


7. ATTENUATION

Attenuation =
Distance ke saath signal strength ka decrease.

Concept:

Strong signal
    ↓
Long cable
    ↓
Weaker signal
    ↓
More distance
    ↓
More degradation


8. NOISE

Signal + Noise

Possible causes:
- Electromagnetic interference
- Crosstalk
- Poor cabling
- Bad connectors

11. REPEATER DOES NOT UNDERSTAND

Repeater generally does not perform:

- MAC learning
- IP routing
- TCP processing
- DNS
- HTTP processing
- BGP
- OSPF
- VLAN-aware forwarding

It operates at Layer 1.

13. MAC ADDRESS

Suppose:

Source MAC:
AA-AA-AA-AA-AA-01

Destination MAC:
BB-BB-BB-BB-BB-02

Repeater does not use the MAC address for forwarding decisions.

It does not maintain:

MAC → Port

That is switch behavior.


14. REPEATER VS HUB

Repeater:
- Layer 1
- Signal regeneration/repetition
- Usually extends physical segments

Hub:
- Layer 1
- Multiport repeater
- Repeats incoming signal to multiple ports

Simple:

Repeater = physical signal repetition

Hub = multiport repeater


15. REPEATER VS SWITCH

Repeater:
- Layer 1
- Physical signal
- No MAC learning
- No selective frame forwarding

Switch:
- Layer 2
- Ethernet frames
- MAC learning
- Selective forwarding
- Usually full-duplex links


16. REPEATER VS ROUTER

Repeater:
- Layer 1
- Signal regeneration
- No routing

Router:
- Layer 3
- IP packets
- Routing table
- Connects different IP networks


17. COLLISION DOMAIN

A repeater does not create a Layer-2 boundary.

In shared Ethernet designs:

PC1 ---- Segment ---- Repeater ---- Segment ---- PC2

The extended shared environment can remain one collision domain.


18. BROADCAST DOMAIN

Repeater does not separate broadcast domains.

It operates below Layer 2.

Router can separate broadcast domains.


19. HALF DUPLEX

Historical/shared Ethernet repeater environments generally used:

Half Duplex

Meaning:
Transmission direction is shared and simultaneous transmission can cause
collisions.


20. CSMA/CD

Full form:

Carrier Sense Multiple Access with Collision Detection

Classic process:

1. Check if medium is free.
2. Transmit.
3. If collision occurs, detect it.
4. Stop transmission.
5. Wait for random backoff.
6. Retry.

Important:
This is mainly relevant to legacy shared half-duplex Ethernet.
Modern switched full-duplex Ethernet does not normally use CSMA/CD.


21. PROPAGATION DELAY

Signals need time to travel.

More physical distance:
    ↓
More propagation delay

Repeaters add physical propagation delay.

Classic Ethernet standards therefore had limits on:
- Segment length
- Number of repeaters
- Timing
- Collision detection


22. CLASSIC 5-4-3 RULE

Historical Ethernet rule:

- Maximum 5 network segments
- Maximum 4 repeaters
- Maximum 3 populated segments

Important:
This is a historical shared/repeater-based Ethernet rule.

It is not a modern switched Ethernet design rule.


23. SIGNAL REGENERATION VS AMPLIFICATION

Amplifier:

Weak Signal + Noise
      ↓
Amplify
      ↓
Stronger Signal + Noise

Repeater:

Degraded Signal
      ↓
Recover/Regenerate
      ↓
New regenerated signal

Repeater is not simply a dumb amplifier.

25. BROADCAST THROUGH REPEATER

Repeater does not understand broadcast semantics.

If a physical broadcast transmission comes in:

Source
  ↓
Repeater
  ↓
Other segment

Signal is regenerated and transmitted.


26. UNICAST THROUGH REPEATER

PC1 → PC2

PC1
 ↓
Repeater
 ↓
PC2

Repeater does not inspect destination MAC to decide whether to forward.


27. MULTICAST THROUGH REPEATER

Repeater does not perform Layer-2 multicast filtering.

It operates at physical signaling level.


28. WHY REPEATERS BECAME LESS COMMON

Limitations:
- Shared collision domains in legacy Ethernet
- Half-duplex
- Collision overhead
- Limited scalability
- No MAC filtering
- No intelligent forwarding

Switches solved many of these issues.


29. SWITCH ADVANTAGES

Switch:
- MAC learning
- Selective forwarding
- Separate collision domain per port in typical Ethernet
- Full duplex
- Better performance
- Better scalability

31. WIRELESS REPEATER

Consumer Wi-Fi repeaters/range extenders are not necessarily
pure Layer-1 Ethernet repeaters.

They may:
- Receive Wi-Fi frames
- Retransmit them
- Bridge wireless traffic
- Use a wireless backhaul
- Use multiple radios

Therefore:
Wi-Fi range extender != automatically a classic Layer-1 repeater.


32. MODERN FIBER CONTEXT

Long-distance optical communication can use regeneration and amplification
technologies.

But modern optical repeaters/regenerators can be much more sophisticated
than classic Ethernet repeaters.

Technology-specific implementation matters.

37. COMMON MISCONCEPTIONS

Wrong:
"Repeater forwards packets."

Better:
"Repeater regenerates/retransmits physical signals."

Wrong:
"Repeater checks destination MAC."

Correct:
"Repeater does not use MAC addresses for forwarding decisions."

Wrong:
"Repeater separates networks."

Correct:
"Repeater does not create a Layer-3 boundary."

Wrong:
"Repeater increases bandwidth."

Correct:
"Repeater primarily extends/regenerates physical signaling; it does not
magically increase the link capacity or eliminate shared-medium limitations."


38. INTERVIEW QUESTIONS

Q: What is a repeater?
A:
A Layer-1 device that receives and regenerates/retransmits physical signals.

Q: Which OSI layer does a repeater operate at?
A:
Layer 1, Physical Layer.

Q: Does a repeater understand MAC addresses?
A:
No.

Q: Does a repeater route IP packets?
A:
No.

Q: What problem does a repeater solve?
A:
It helps extend physical communication by regenerating signals that would
otherwise degrade over distance.

Q: What is attenuation?
A:
Signal strength reduction over distance.

Q: Repeater vs amplifier?
A:
An amplifier mainly increases signal amplitude and can also amplify noise;
a repeater recovers/regenerates and retransmits the signal.

Q: Repeater vs hub?
A:
A hub is essentially a multiport repeater.

Q: Repeater vs switch?
A:
Repeater operates at Layer 1; switch operates primarily at Layer 2 and
uses MAC addresses for forwarding.

Q: Does repeater separate collision domains?
A:
No. In legacy shared Ethernet, repeaters extend the same collision domain.

Q: Does repeater separate broadcast domains?
A:
No.

Q: Why were repeaters replaced by switches?
A:
Switches provide MAC learning, selective forwarding, full duplex,
separate collision domains and better scalability.


39. GOLDEN MEMORY

REPEATER:
Signal → Receive → Recover/Regenerate → Retransmit

HUB:
Signal → Repeat to multiple ports

SWITCH:
Frame → Destination MAC → Correct port

ROUTER:
IP Packet → Routing Table → Next Hop


40. FINAL ONE-LINE SUMMARY

Repeater is a Layer-1 device that regenerates physical signals to extend
communication across physical segments, without understanding MAC/IP
addresses or making Layer-2/Layer-3 forwarding decisions.
