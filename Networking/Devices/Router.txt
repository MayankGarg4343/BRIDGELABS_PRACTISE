TOPIC: ROUTER — Full Notes


1. DEFINITION

Router ek Layer-3 (Network Layer) networking device hai jo different
IP networks/subnets ke beech packets ko forward karta hai.

Simple definition:

Router destination IP address ko dekhta hai, routing table se best route
find karta hai, next hop/output interface decide karta hai, aur packet ko
next network ki taraf forward karta hai.


2. BASIC MENTAL MODEL

Switch:

MAC Address → Port

Router:

Destination IP → Next Hop / Interface

Golden rule:

SWITCH = MAC → PORT
ROUTER = IP → NEXT HOP


3. OSI LAYER

Traditional Router:

- Packet

4. WHY ROUTER EXISTS

Suppose:

Network A:
192.168.1.0/24

Network B:
192.168.2.0/24

Network A ke device ko Network B ke device se communicate karna hai.

Simple Layer-2 switching enough nahi hai.

Flow:

Network A
    |
  Router
    |
Network B

Router different IP networks ke beech Layer-3 communication provide karta hai.


5. REAL-WORLD ANALOGY

Router ko ek city ke major traffic junction ki tarah samjho.

Packet = Vehicle

Destination IP = Destination address

Routing Table = Road map

Next Hop = Next junction

Output Interface = Road

Router ka question:

"Destination tak pahunchne ke liye packet ko kis direction mein bhejna hai?"

16. DEFAULT ROUTE

0.0.0.0/0

   ↓

17. LONGEST PREFIX MATCH

Extremely important routing concept.

Suppose routing table:

10.0.0.0/8
10.10.0.0/16
10.10.20.0/24
0.0.0.0/0

Destination:

10.10.20.50

Multiple routes match kar rahe hain.

Router most specific route choose karega:

10.10.20.0/24

Because:

/24 > /16 > /8 > /0

This is called:

Longest Prefix Match (LPM)


18. WHY LONGEST PREFIX MATCH?

Broad route:

10.0.0.0/8

More specific:

10.10.0.0/16

Even more specific:

10.10.20.0/24

Router sabse specific matching information ko prefer karta hai.


19. NEXT HOP

Next hop wo next router/device hota hai jisko packet ko destination ki
direction mein forward karna hota hai.

Example:

Destination:
10.10.10.0/24

Next Hop:
192.168.2.2

Meaning:

"10.10.10.0/24 ke liye packet pehle 192.168.2.2 ko bhejo."


20. HOP-BY-HOP ROUTING

Example:

PC → R1 → R2 → R3 → Server

PC:
Next Hop = R1

R1:
Next Hop = R2

R2:
Next Hop = R3

R3:
Destination directly connected

Important:

Har router independently next-hop decision leta hai.


21. ROUTER KO COMPLETE PATH PATA HONA ZAROORI NAHI

PC ko generally complete path:

PC → R1 → R2 → R3 → Server

pata hona zaroori nahi.

PC ko mainly pata hota hai:

- Destination local hai
OR
- Destination remote hai, so default gateway/route use karo.

Routers independently forwarding decisions karte hain.


22. ARP VS ROUTING

Routing answer karta hai:

"Destination IP ke liye kaunsa next hop/interface use karna hai?"

ARP answer karta hai:

"Local IPv4 next-hop IP ka MAC address kya hai?"

Therefore:

Routing:

Destination IP
    ↓
Next Hop / Interface

ARP:

Next-Hop IPv4
    ↓
MAC Address


23. IPv6 AND NDP

Memory:

24. COMPLETE PACKET FLOW

Topology:

PC1
192.168.1.10
    |
  Switch
    |
Router
G0/0 = 192.168.1.1
G0/1 = 192.168.2.1
    |
  Switch
    |
Server
192.168.2.20


PC1 wants:

192.168.2.20


STEP 1:
Application data create hota hai.

STEP 2:
Transport Layer TCP/UDP header add karta hai.

STEP 3:
IP packet create hota hai:

Source IP:
192.168.1.10

Destination IP:
192.168.2.20

STEP 4:
PC routing decision karta hai.

Destination local subnet mein nahi hai.

Therefore:

Use default gateway:
192.168.1.1

STEP 5:
PC ARP se gateway ka MAC find karta hai.

STEP 6:
PC Ethernet frame create karta hai:

Source MAC = PC MAC
Destination MAC = Router G0/0 MAC

STEP 7:
PC → Switch → Router

STEP 8:
Router frame receive karta hai.

STEP 9:
Router destination IP dekhta hai:

192.168.2.20

STEP 10:
Routing table lookup karta hai.

Finds:

192.168.2.0/24 → G0/1

STEP 11:
Router TTL decrease karta hai.

STEP 12:
Router next-hop/server MAC resolve karta hai if needed.

STEP 13:
Router new Ethernet frame create karta hai:

Source MAC = Router G0/1 MAC
Destination MAC = Server MAC

STEP 14:
Packet:

Router → Switch → Server

STEP 15:
Server packet receive karta hai.


25. VERY IMPORTANT L2 VS L3 CHANGE

Original frame:

Source MAC:
PC MAC

Destination MAC:
Router G0/0 MAC


After router:

Source MAC:
Router G0/1 MAC

Destination MAC:
Server MAC


But IP packet:

Source IP:
192.168.1.10

Destination IP:
192.168.2.20

generally remains unchanged across routing hops, except fields affected
by normal forwarding or features such as NAT.


26. MAC ADDRESS CHANGES AT EVERY ROUTER HOP

Example:

Hop 1:

PC MAC → R1 MAC

Hop 2:

R1 MAC → R2 MAC

Hop 3:

R2 MAC → Server MAC


Important:

MAC is local to the Layer-2 link.

IP provides the Layer-3 end-to-end addressing.


27. TTL

TTL = Time To Live

IPv4 packet header mein TTL field hoti hai.

Each router hop par normally:

TTL = TTL - 1

Example:

Initial TTL = 64

R1 → 63

R2 → 62

R3 → 61

Purpose:

Routing loops mein packet indefinitely circulate na kare.


28. IPV6 HOP LIMIT

IPv6 mein TTL equivalent:

Hop Limit

Each router:

Hop Limit - 1


Memory:

IPv4 → TTL
IPv6 → Hop Limit


29. ROUTING LOOP

Example:

↑     ↓
+-----+

Wrong routing ke wajah se packet loop kar sakta hai.

Example:

Packet
 ↓
R1
 ↓
R2
 ↓
R1
 ↓
R2
 ↓
...

TTL/Hop Limit eventually expire hota hai.

Therefore:

Router broadcast domains separate karta hai.


31. ROUTER AND BROADCAST DOMAIN

Switch:

Different interfaces ke beech Layer-2 broadcast boundary create karta hai.


32. SWITCH VS ROUTER

Switch:

- Primary Layer: Layer 2
- Main address: MAC
- Main data: Ethernet Frame
- Main table: MAC Address Table
- Primary job: LAN/Layer-2 forwarding

Router:

- Primary Layer: Layer 3
- Main address: IP
- Main data: IP Packet
- Main table: Routing Table
- Primary job: Inter-network forwarding

34. NAT

NAT = Network Address Translation

NAT translates IP addresses.

Common scenario:

Private network:

192.168.1.0/24

Router

Public Internet


35. WHY NAT?

Private IP addresses Internet par directly routable nahi hote.

Suppose:

PC1:
192.168.1.10

PC2:
192.168.1.11

PC3:
192.168.1.12

Router has public IP:

203.0.113.10

NAT/PAT can allow multiple internal devices to access the Internet
using a shared public IPv4 address.


36. PAT

PAT = Port Address Translation

Also commonly called:

NAT Overload

Example:

Internal:

192.168.1.10:50000
192.168.1.11:50001

Public side:

203.0.113.10:40001
203.0.113.10:40002

Router translations maintain connection mappings.


37. NAT VS ROUTING

Routing:

"Packet ko kahan bhejna hai?"

NAT:

"Packet ke address/port ko translate karna hai ya nahi?"

Important:

Routing aur NAT same cheez nahi hain.

Router NAT ke bina bhi routing kar sakta hai.

- Manually configured
- Simple
- Predictable
- Small/stable networks mein useful
- Large networks mein maintenance difficult

66. COMMON ROUTER MISTAKES

Mistake 1:
"Router MAC address ke basis par routing karta hai."

Correct:
Routing decision destination IP ke basis par hota hai.

Mistake 2:
"Router har packet ka destination IP change karta hai."

Correct:
Normal routing mein destination IP same rehta hai.
NAT ek separate function hai.

Mistake 3:
"Router aur switch same hain."

Correct:

Switch → Layer 2
Router → Layer 3

Mistake 4:
"Default gateway Internet hota hai."

Correct:
Default gateway local next-hop router hota hai.

Mistake 5:
"Router broadcasts ko forward karta hai."

Correct:
Layer-2 broadcasts normally router interfaces ke across forward nahi hote.

Mistake 6:
"ARP routing karta hai."

Correct:

Routing:
IP → Next Hop/Interface

ARP:
Next-Hop IPv4 → MAC


67. INTERVIEW QUESTIONS

Q1. What is a router?

A:
A Layer-3 device that forwards IP packets between different networks.

Q2. Which OSI layer does a router operate at?

A:
Layer 3.

Q3. What is routing?

A:
Destination IP ke basis par packet ke liye appropriate path/next hop
select karna.

Q4. What is a routing table?

A:
Routes ka collection jo packet forwarding decisions mein help karta hai.

Q5. What is a default route?

A:
IPv4 mein 0.0.0.0/0; jab more-specific route match nahi karta tab use hota hai.

Q6. What is longest prefix match?

A:
Multiple matching routes mein most specific prefix ko choose karna.

Q7. What is a next hop?

A:
Destination ki direction mein packet ka next router/device.

Q8. What is a default gateway?

A:
Host ka local router used to reach destinations outside the local subnet.

Q9. Does a router forward Layer-2 broadcasts?

A:
Normally no.

Q10. What is TTL?

A:
IPv4 header field jo each router hop par decrement hoti hai to prevent
routing loops.

Q11. IPv6 mein TTL ka equivalent?

A:
Hop Limit.

Q12. What is NAT?

A:
Network Address Translation; IP addresses ko translate karta hai.

Q13. What is PAT?

A:
Port Address Translation; multiple private hosts ko shared public IPv4
address use karne mein help karta hai.

Q14. Static vs dynamic routing?

A:
Static routes manually configured hote hain; dynamic routes routing
protocols se learned/updated hote hain.

Q15. What is OSPF?

A:
A link-state interior routing protocol commonly used for internal
network routing.

Q16. What is BGP?

A:
The primary inter-domain routing protocol used between autonomous systems
and for policy-based Internet routing.

Q17. What is RIB?

A:
Routing Information Base, routing/control-plane information.

Q18. What is FIB?

A:
Forwarding Information Base, optimized data-plane forwarding structure.

Q19. Why does MAC change at every router hop?

A:
Har Layer-3 hop par packet ko new Layer-2 frame mein encapsulate kiya jata
hai, isliye source/destination MACs local link ke according change hote hain.

Q20. Does the destination IP change at every router?

A:
Normally no. Destination IP generally remains the final destination IP,
except when mechanisms such as NAT modify it.

Router ek Layer-3 networking device hai jo destination IP address aur
routing table ke basis par packets ko different networks ke beech
forward karta hai, longest-prefix match se best route select karta hai,
next hop/output interface determine karta hai, har routed hop par packet
ko new Layer-2 frame mein encapsulate karta hai, TTL/Hop Limit decrease
