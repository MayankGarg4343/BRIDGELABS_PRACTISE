TOPIC: VPN (Virtual Private Network) — Full Notes

1. DEFINITION

VPN = Virtual Private Network.

VPN ek logical private tunnel hai jo public/untrusted/shared network ke
upar secure connectivity provide karta hai.

VPN khud ek single protocol nahi hai.

Examples of VPN technologies/protocols:
- IPsec
- WireGuard
- OpenVPN
- TLS-based VPN solutions


2. WHY VPN EXISTS

VPN ka main purpose:

- Secure remote access
- Site-to-site connectivity
- Private network connectivity over Internet
- Confidentiality
- Integrity
- Authentication
- Cloud connectivity
- Hybrid cloud connectivity
- Secure administration
- Branch connectivity

- Individual user/device → corporate network

10. VPN SECURITY PROPERTIES

Confidentiality:
- Unauthorized parties cannot easily read protected traffic.

Integrity:
- Detects unauthorized modification.

Authentication:
- Verifies users/devices/endpoints.

Authorization:
- Determines what authenticated users/devices can access.


11. IPSEC

IPsec = Internet Protocol Security.

IPsec is a suite of protocols/mechanisms used to secure IP communication.

Important components:
- AH
- ESP
- IKE


12. ESP

ESP = Encapsulating Security Payload.

Provides:
- Confidentiality
- Integrity
- Authentication-related protection

ESP is very important in modern IPsec VPN deployments.


13. AH

AH = Authentication Header.

Provides:
- Integrity
- Authentication-related protection

Does not provide encryption.

ESP is more commonly relevant for VPN deployments.


14. IKE

IKE = Internet Key Exchange.

Purpose:
- Negotiate security parameters
- Authenticate peers
- Establish cryptographic keys
- Establish security associations for IPsec


15. IPSEC MODES

Tunnel Mode:

[New IP Header]
[IPsec]
[Encrypted Original IP Packet]

Commonly used for:
- Site-to-site VPN

Transport Mode:

[Original IP Header]
[IPsec]
[Encrypted Upper-Layer Payload]

Commonly associated with:
- Host-to-host IPsec

18. FULL TUNNEL

All/most traffic goes through VPN.

Laptop
  ↓
VPN
  ↓
Corporate Gateway
  ↓
Internet

Advantages:
- Centralized security
- Centralized monitoring
- Policy enforcement

Disadvantages:
- More bandwidth usage
- Added latency
- Gateway can become bottleneck


19. SPLIT TUNNEL

Only selected traffic goes through VPN.

Example:

10.20.0.0/16
    ↓
VPN

Normal Internet
    ↓
Direct Internet

Advantages:
- Lower VPN bandwidth
- Lower latency for normal Internet traffic

Disadvantages:
- Security/visibility trade-offs
- Endpoint has simultaneous Internet/private access

22. WIREGUARD

WireGuard is a modern VPN protocol.

Common interface:

Check:

Example conceptual configuration:

[Interface]
Address = 10.100.0.2/24
PrivateKey = <client-private-key>

[Peer]
PublicKey = <server-public-key>
Endpoint = vpn.example.com:51820
AllowedIPs = 10.20.0.0/16
PersistentKeepalive = 25

Never expose private keys in Git or documentation.

28. VPN AND MTU

VPN adds headers/encapsulation overhead.

Original packet
     +
VPN overhead
     =
Larger packet

If MTU is too large for the path:

- Fragmentation
- PMTUD problems
- Large packets fail
- Some applications work and others fail

Commands:

ping -M do -s <size> <destination>

31. COMMON VPN PROBLEMS

VPN doesn't connect:
- Endpoint unreachable
- Firewall
- Authentication failure
- Wrong key/certificate
- Wrong configuration

VPN connects but internal IP doesn't work:
- Routing problem
- Firewall
- ACL
- Return route

IP works but hostname doesn't:
- DNS problem

Small packets work but large packets fail:
- MTU/PMTUD problem

VPN connects but Internet stops:
- Full tunnel/default route issue

Some internal networks work and others don't:
- Route/ACL issue

One-way traffic:
- Return route
- Firewall
- NAT
- Asymmetric routing

VPN is slow:
- High latency
- Low bandwidth
- VPN gateway CPU
- Encryption overhead
- Congestion
- MTU problems

41. VPN VS MPLS

MPLS:
- Forwarding/provider technology

VPN:
- Secure/private logical connectivity

MPLS does not automatically mean encryption.

An MPLS-based VPN can provide logical separation, while encryption can
be added separately if required.


42. CRYPTOGRAPHY

Symmetric encryption:
- Same secret key used for encryption/decryption
- Examples: AES, ChaCha20

Asymmetric cryptography:
- Public/private key pair
- Used for identity/authentication/key exchange

Integrity:
- Ensures unauthorized modification can be detected

Modern VPN protocols often use authenticated encryption.

45. INTERVIEW Q&A

Q: What is VPN?
A:
Virtual Private Network. It creates logical private connectivity over an
untrusted/shared network and commonly provides encryption, integrity and
authentication.

Q: Is VPN a protocol?
A:
No. VPN is an architecture/concept.

Q: Name VPN protocols/technologies.
A:
IPsec, WireGuard, OpenVPN and TLS-based VPN technologies.

Q: What is tunneling?
A:
Encapsulating traffic inside another transport so it can travel through
an underlying network.

Q: What is IPsec?
A:
A suite of protocols/mechanisms for securing IP communication.

Q: What is ESP?
A:
Encapsulating Security Payload. It provides confidentiality and
integrity/authentication-related protection.

Q: What is AH?
A:
Authentication Header. Provides integrity/authentication-related
protection but no encryption.

Q: What is IKE?
A:
Internet Key Exchange. Negotiates security parameters and keys for IPsec.

Q: Tunnel mode vs transport mode?
A:
Tunnel mode protects/encapsulates the complete original IP packet.
Transport mode protects the upper-layer payload while retaining the
original IP header structure.

Q: What is site-to-site VPN?
A:
A secure tunnel connecting two networks through VPN gateways.

Q: What is remote access VPN?
A:
A secure tunnel connecting an individual client to a private network.

Q: What is split tunneling?
A:
Only selected traffic goes through VPN.

Q: What is full tunneling?
A:
Most/all traffic goes through VPN.

Q: Why can VPN cause MTU problems?
A:
VPN adds encapsulation overhead, reducing available payload size.

Q: What is NAT-T?
A:
NAT Traversal allows IPsec traffic to work more reliably through NAT,
commonly using UDP 4500.

Q: Is VPN the same as proxy?
A:
No. VPN can operate at the network level; proxy is generally
application-level.

Q: Is MPLS encrypted?
A:
Not inherently. MPLS provides provider networking/forwarding and
logical separation; encryption is separate.

Q: How do you check WireGuard?
A:
sudo wg show

Q: How do you troubleshoot VPN routing?
A:
ip route
ip route get <destination>

49. ONE-LINE FINAL SUMMARY

VPN is a logical private tunnel over an untrusted/shared network in which
traffic is routed into the VPN, protected/encrypted and encapsulated,
transported across the underlying network, then decrypted and
decapsulated at the destination VPN endpoint and forwarded to the
private destination.
