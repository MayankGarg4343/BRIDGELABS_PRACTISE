TOPIC: WAN (Wide Area Network) — Full Notes

1. DEFINITION

WAN = Wide Area Network.

WAN ek network hai jo geographically far-away networks/sites ko connect karta hai.

Typical scope:
- Multiple cities
- Multiple states
- Multiple countries
- Multiple continents

Core definition:
WAN ka purpose geographically separated LANs/networks ko connect karna hai.

16. MAC VS IP DURING WAN TRAVEL

Very important.

Final destination IP:

    10.20.1.10

Generally end-to-end destination IP same rehta hai during routed forwarding.

But Layer-2 frame information is hop-by-hop.

Example:

Router A → Router B:

    Source MAC = Router A
    Destination MAC = Router B

Router B → Router C:

    Source MAC = Router B
    Destination MAC = Router C

Therefore:

    IP destination:
    Final destination

    Layer-2 destination:
    Changes hop-by-hop

32. WAN LATENCY

WAN generally has higher latency than a local LAN because:
- Geographic distance is larger
- More network hops
- Longer physical paths
- Provider routing
- Queuing/congestion

Latency depends on:
- Distance
- Fiber path
- Number of hops
- Routing
- Congestion
- Queuing


33. BANDWIDTH VS LATENCY

Bandwidth:
- Amount of data that can be transmitted per unit time.

Latency:
- Time taken for data/packet to travel from source to destination.

Important:

High bandwidth does not automatically mean low latency.

Example:

    10 Gbps link
    can still have
    significant WAN latency.

- Interface errors
- Routing issues
- Firewall
- MTU issues

Basic test:

More advanced:

Typical Ethernet MTU:

    1500 bytes

VPN/tunneling can add extra headers.

Concept:

    Original Packet
          ↓
      VPN Header
          ↓
    Larger Packet

Incorrect MTU/PMTUD behavior can cause:
- Some applications work while others fail
- Large packets fail
- VPN problems
- Intermittent connectivity
- Websites/API requests hanging

46. COMMON MISCONCEPTIONS

Misconception:
"Internet and WAN are the same."

Correct:
WAN is a wide-area networking concept.
Internet is the global public interconnection of networks.
A private enterprise WAN does not require the public Internet.

Misconception:
"MPLS is WAN."

Correct:
MPLS is a networking/forwarding technology that can be used in WANs.

Misconception:
"Router is WAN."

Correct:
Router is a network device used to connect/route between networks.

Misconception:
"All WAN traffic uses Internet."

Correct:
Private WANs can use MPLS, leased circuits, carrier Ethernet, private optical networks and other transport technologies.

Misconception:
"High bandwidth means low latency."

Correct:
Bandwidth and latency are different properties.

Misconception:
"Ping works, so application works."

Correct:
Ping only tests ICMP reachability. Firewall, port, service or application problems can still exist.


47. INTERVIEW Q&A

Q1. What is WAN?
A:
WAN stands for Wide Area Network. It connects geographically distributed networks/sites over large distances.

Q2. Why do we need WAN?
A:
To connect offices, data centers, branches and other networks located across cities, countries or continents.

Q3. What is the difference between LAN and WAN?
A:
LAN covers a local area and commonly uses switches for local connectivity. WAN connects geographically separated networks using routers and wide-area transport.

Q4. What is the difference between MAN and WAN?
A:
MAN generally covers metropolitan/city-scale connectivity, while WAN covers larger geographic areas such as multiple cities, countries or continents.

Q5. Is WAN a protocol?
A:
No. WAN is a network scope/classification.

Q6. What technologies can be used for WAN?
A:
MPLS, IPsec VPN, SD-WAN, leased lines, carrier Ethernet, fiber, cellular and satellite connectivity.

Q7. What is MPLS?
A:
Multiprotocol Label Switching is a forwarding technology commonly used in provider and enterprise WAN networks.

Q8. What is BGP?
A:
Border Gateway Protocol is a routing protocol used to exchange reachability information between autonomous systems and is fundamental to Internet routing.

Q9. What happens when a packet travels through multiple WAN routers?
A:
Each router receives the packet, examines the destination IP, performs a routing lookup, selects a next hop and forwards it toward the destination.

Q10. Does destination IP change at every router?
A:
Normally the final destination IP remains the same during standard routing, while Layer-2 framing changes hop-by-hop. Some technologies such as NAT can modify IP addresses, but that is a separate function.

Q11. Why is WAN latency usually higher than LAN latency?
A:
Because WAN traffic travels greater geographic distances and may pass through more links, routers and queues.

Q12. How do you troubleshoot WAN connectivity from Linux?
A:
Use:
    ip link
    ip addr
    ip route
    ip route get <destination>
    ping <destination>
    tracepath <destination>
    mtr <destination>
    nc -vz <destination> <port>
    tcpdump

Q13. What is WAN redundancy?
A:
Using multiple paths, links, routers or providers so that connectivity can continue when one path fails.

Q14. Is the Internet a WAN?
A:
The Internet is a global interconnection of networks and can be viewed as a global wide-area environment, but WAN and Internet are not synonymous. Private WANs also exist.

52. ONE-LINE SUMMARY

WAN is a wide-area networking environment that connects geographically distributed networks; data travels from the source LAN to a router, crosses one or more WAN/provider routers through routing decisions, reaches the destination router, and is finally delivered across the destination LAN to the target device.
