Answer these after completing the lab:

What is the difference between cat and less?
answer - cat displays the whole content of the file directly on the screen and less used to display the content but also provides the 	various options to navigate the data line n nor next page and b for back page and we also view the content line by line.

When would you use tail -f?
answer - we will use this command to see the latest logs during the production and we call it live monitoring.

What is the difference between > and >>?
answer - > overwrites the content in the file and >> appends the content in the file.

What is a pipe (|)?
answer - it is used for passing the one commands data to the next command. Example -> command A | command B.

Why shouldn't you use cat on a huge log file?
answer - because it provides you the whole data directly and it is not manageable to read that lots of data.
